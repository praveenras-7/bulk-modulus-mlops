\# Bulk Modulus Prediction - MLOps Pipeline



Production-ready ML system for predicting bulk modulus of materials using CBFV and materials informatics.



\## 🎯 Overview



\- \*\*Dataset\*\*: 83,989 material compositions from Materials Project

\- \*\*Method\*\*: CBFV (Composition-Based Feature Vectors)

\- \*\*Models\*\*: RandomForest, XGBoost, GradientBoosting, Neural Networks

\- \*\*Deployment\*\*: Azure ML with FastAPI
